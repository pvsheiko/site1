# Gvozdik studio

Next.js 16 + TypeScript, обычный CSS, локальные Manrope Variable (кириллица/латиница, OFL в пакете @fontsource-variable/manrope). Молочный фон, типографическое оформление и авторская SVG-графика. Инструкции агента находятся отдельно в /workspace/website-designer-agent; приложение — в этом каталоге.

## Работа

Node.js 24 и npm. Из `site/`:

```sh
npm ci
npm run dev -- --hostname 0.0.0.0 --port 3000
```

Проверки и production:

```sh
npm run lint
npm run build
npm run start -- --hostname 0.0.0.0 --port 3000
```

Главная должна вернуть HTTP 200 и содержать заголовок «Фото и видео для брендов женской одежды». Проверить якоря `#work`, `#about`, `#contact`, ссылки на Instagram, `/robots.txt`, `/llms.txt`, `/opengraph-image`, неизвестную страницу (404). Серверные компоненты: основной текст доступен без JS. Шрифты загружаются локально, внешние ключи и база данных не нужны.

## Материалы и публикация

Встроены три реальные фотографии из переданного пользователем архива. Белый образ показан на первом экране; в галерее — белый, чёрный и красный образы с открытием полных кадров. Дополнительное портфолио и контакт ведут в Instagram @gwozdik. Отдельные кейсы и видео ещё не предоставлены. Графика не изображает работы студии. Не добавлять вымышленные проекты, фото других фотографов или сгенерированное портфолио.

Для развития портфолио получить полные серии и видео, роли студии в каждой съёмке и подтверждённый контакт. После этого добавить кейсы и видео. Фото — в `public/images/` в WebP/AVIF с описательным alt; исходники — вне public. Видео с постером и управлением воспроизведением, без автоматической загрузки тяжёлых файлов.

Перед production-сборкой задать `SITE_URL` равным реальному HTTPS-домену (пример названия переменной в `.env.example`). До этого canonical отсутствует, sitemap пуст, Next использует локальный базовый адрес для OG — индексация и превью соцсетей не готовы для публикации. После задания домена пересобрать и проверить абсолютные адреса, OG и sitemap.

Хостинг должен поддерживать Next.js 16 / Node.js 20.9+. При импорте в Vercel Root Directory = `site`. Публикация пока не выполнена. Для коммерческого сайта Vercel Hobby не подходит по условиям тарифа; выбрать Pro или другой подходящий хостинг.
